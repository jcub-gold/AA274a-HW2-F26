# Principles of Robot Autonomy I HW2
Homework 2 code for Principles of Robot Autonomy I
## Dependencies
Python package dependencies for this assignment are listed in the `requirements.txt` file and can be automatically installed by
```
pip install -r requirements.txt
```
## Submission
Upload `P1_trajopt.py`, `P2_dynamics.py`, and `P3_lqr.py` to the HW2 Code assignment on Gradescope. Do not rename the files or change the function signatures.

`trajectory_tracking.py` is a provided controller for the ungraded navigator section prep (Problem 4); you do not need to modify it.
